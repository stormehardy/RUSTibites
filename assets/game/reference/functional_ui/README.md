# Functional/UI parity capture

Menu sessions activate the Welcome UI roots for Load, Settings (Graphics/Gameplay/Hotkeys), New Game/Scenario, Bibite Library/Editor (Genes/Brain), Achievements, Additional Tools, Credits, Workshop, Scenario Editor; in-world sessions press the toolbar buttons (Placer/UserActions/View/DynamicParameters/AncestralLineage/Information/Settings). `manifest.json` maps each session to node paths/labels/control state; screenshots/overlays are per session. Existing atlas sessions preserved.

## Click-effect behavioral reference

`behavioral_reference.json` records each menu/toolbar/settings/inspector action with before/after counts/tools/zones, active panels, new labels/texts/dialogs, clicked node hit and a `changed` verdict. Generated by `tools/assets/capture_ui_behavior.py` in the hidden game.

## Settings/save-load/control behavior

`control_behavior.json` extends click-effect ground truth with: settings Toggle/Slider/Dropdown
before→after values/options and setting label contexts; Load Game and Save Game browser panel texts/buttons/
images; placer tool property controls (Material Plant/Meat, Pellet Size Factor, Pellet Number, sliders);
KILL confirmation full texts/buttons; inspector Lay Egg/tag attempts (buttons not found in that StatsPanel
state, documented). Plugin routes `/d/control_dump` and `/d/control_set` provide exact control state.

## Library/New Game flow ground truth

`library_newgame_behavior.json` + sessions cover Bibite Library selector, Create New/Templates, gene editor controls/randomize, brain editor add-node/synapse inventory, New Game/scenario option controls, scenario editor zone/challenge panels; screenshots/overlays under this directory.

## Resolved gap flows

gap_flows.json covers path-based CreateNew/Edit/Genes, gene slider edits, SaveAndContinue/Submit, save creation/load browser; save_dialogs.json records load/delete and save-overwrite attempts (hidden lab list did not surface the created slot; test save removed).
