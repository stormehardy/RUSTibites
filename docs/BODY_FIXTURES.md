# Synthetic body fixtures

Deterministic Rust-written save fixtures for body systems Default does not exercise. Generated by
`cargo run --release -p bibites-cli --example make_body_fixtures` from the game-written
`testdata/parity/default/game_scenario_seed_600_nospawn.zip` base. Mutations are disabled in the fixture
settings and health/energy are set to the loaded max values so the game and Rust load identical state.

| fixture | setup | expected invariants |
|---|---|---|
| `egg_lay_hatch.zip` | one mature bibite, egg progress 1, LayTime/HatchTime 1 s, forced EggProduction/Want2Lay | lays at least one egg, child hatches (birth observed), egg layer n_laid>0 |
| `combat_attack.zip` | two adults 6 u apart, facing; forced Want2Attack, high MouthMusclesWAG, zero ArmorWAG; both at health 132 / energy 130 | total health drops by >1 HP over 180 ticks (bite/damage path) |
| `fat_armor_inflate.zip` | one adult, FatWAG/ArmorWAG/WombWAG high, fat amount above base capacity | fat inflates (`inflate_factor>0`), Tail collider offset beyond −4.7·d1 and size uses the 5→8.5 / 7→10.5 lerp |
| `starvation_death.zip` | one adult, energy 0, health 1 | dies by ~tick 249, corpse handoff |

Rust invariants: `cargo test --release -p bibites-cli --test body_fixtures` (skips if fixtures absent).

Parity command pattern (hidden game):

```powershell
python tools\parity\capture.py --save crates\bibites-cli\tests\fixtures\body\egg_lay_hatch.zip `
    --ticks 210 --seed 12345 --feeding --out testdata\parity\fixtures\body\game_egg_lay_hatch
rustibites run crates\bibites-cli\tests\fixtures\body\egg_lay_hatch.zip --ticks 210 --seed 12345 `
    --capture testdata\parity\fixtures\body\rust_egg_lay_hatch
```

Use the same pattern for `combat_attack` (180 ticks), `fat_armor_inflate` (3 ticks), and
`starvation_death` (300 ticks). **Recapture is required after the growth/health/mutation fixture fix**
(the previous `assets/game/reference/body_fixtures/summary.json` used the old fixtures whose game energy
loaded as 1000 while Rust kept the saved value). Compare `events.jsonl`, `ticks.jsonl` body stats and
`feeding.jsonl` per-bibite health/stomach (combat) or egg/birth events (egg fixture). Red-death/world-tool
terms are owned by world-dev and are not part of these body fixtures.
