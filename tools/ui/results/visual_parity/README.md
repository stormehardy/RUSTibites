## When native references are ready

Regenerate from a clean viewer HEAD:

```powershell
cargo build --release -p bibites-view
python tools/ui/run_visual_parity.py --diagnostics
```

The runner tries `assets/game/reference/functional_ui_native/` first, falls back to legacy refs only while
native per-session captures are missing, and records `native_reference`/`pixel_authoritative`/
`ref_sharpness`/`rescale_blur_suspect` per session. For the release gate use:

```powershell
python tools/ui/run_visual_parity.py --strict --require-native-references --diagnostics
```

`--diagnostics` adds per-session alpha/color/edge diagnostics and a render/reference sharpness ratio for
separating TMP SDF/font blur from geometry error. The full renders and diff heatmaps live under
`target/ui_visual_diff/` (gitignored); this directory keeps only the compact summary.
